Map

  • HashMap
  • Hashtable
  • LinkedHashMap
  • TreeMap

The Java implementation of java.util.Map which is transpiled into JavaScript.

The JDK type is an interface, but the transpiled JavaScript has no interface concept and the class library resolution is based on the method name and the parameter descriptor. This implementation is therefore a concrete class, which is also used as the common super class of HashMap, LinkedHashMap, TreeMap and Hashtable.
