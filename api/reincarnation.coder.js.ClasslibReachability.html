ClasslibReachability

Computes the method level reachability for the TeaVM class library based JavaScript program. The whole class based closure pulls almost every class through java.lang.Object, so the reachable methods (and the classes which declare them) are computed here to prune the output.

The virtual dispatch is taken into account by propagating the reachable method signatures to the overriding methods of every reachable class.
