NameAllocator

Allocates a unique and valid JavaScript identifier for every class, method and field.

Methods are keyed by their name and parameter descriptor so that an override shares the name of the base method while an overload gets a distinct name. Static and private methods include the declaring class because they are not dynamically dispatched in Java.

Fields are keyed by the declaring class and the field name because JavaScript has only one property namespace, while Java allows a subclass to hide a field with the same name.
