NameAllocator

Allocates a unique and valid JavaScript identifier for every Java class.

The JavaScript coder used to resolve the declared class name and the referenced class name by different rules, so a class whose simple name collided with another class was declared by its simple name but referenced by its canonical name (which is not a valid JavaScript identifier). This allocator is the single source of truth for both sides.

The name of a class is allocated lazily and cached. The first class which claims a name keeps it, so seeding the root class before its dependencies makes the output stable.
