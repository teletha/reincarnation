TranslationException

  • RuntimeException
  • Exception
  • Throwable
  • Serializable

Signals that the bytecode can not be translated into JavaScript.

Unlike the previous behavior which silently dropped the unsupported class, this exception carries the class and the member which caused the failure so that the caller can fix the mapping.
