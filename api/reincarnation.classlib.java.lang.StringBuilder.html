StringBuilder

  • StringBuffer

The Java implementation of java.lang.StringBuilder which is transpiled into JavaScript.

JavaScript strings are immutable, so this implementation keeps the current text and replaces it on every mutation. Every Java overload is declared explicitly because the symbol allocator gives each overload a distinct JavaScript name.
