JavascriptRuntime

The JavaScript runtime that emulates the Java standard library APIs which the JavaScript coder maps to JavaScript.

#Intrinsics provides the primitive operations (string, number, character, long and so on) and is always embedded. #Standard provides the collection classes and is embedded only when the decompiled code actually references one of them.
