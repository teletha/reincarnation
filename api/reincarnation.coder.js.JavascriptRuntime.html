JavascriptRuntime

The JavaScript runtime that emulates the Java standard library APIs which the JavaScript coder maps to JavaScript.

Currently only java.util.List and java.util.Map (and their common implementations) are supported. The runtime is emitted only when the decompiled code actually references one of them, so the output of the code which does not use collections remains unchanged.
