🛠️ Annotation

Native Marks the Java implementation of a JavaScript native API.
Debuggable This annotation is provided for Reicarnation developers. Normally, it should be included in the test code, but due to unavoidable circumstances, it has been exposed in the implementation code.
Unnecessary Marks the class which must not be included in the JavaScript bundle even if it is referenced from the bytecode.
Necessary Marks the class which must be included in the JavaScript bundle even if it is not referenced from the bytecode (for example, a class which is instantiated by reflection).
